  1. Create the new Render Postgres and copy its External Database URL.
  2. On your computer, put it in .env as DATABASE_URL (add ?sslmode=require).
  3. Run python manage.py migrate.
  4. Run python manage.py restore_backup <your-file>.json.gz. Add --flush if you already created an admin there by hand.
  5. Point the web service's DATABASE_URL at the new database and redeploy.

Restore with the same version of the code that made the backup. Order and invoice numbers carry on from where they stopped.
